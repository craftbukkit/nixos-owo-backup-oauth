Local backups to Google Drive.

NixOS OWO Backup is a personal configuration of rclone and a local background service. It uploads selected files from the operator’s computer to that operator’s Google Drive.

Purpose and access

This application is intended only for the operator’s own use. This website documents the application for its Google OAuth consent configuration. It does not offer public sign-up, account linking, file uploads, or a hosted backup service.

The configured OAuth permission is drive.file. It allows the utility to create backup files and manage files created by this application, rather than granting access to every file in the account.

Backup behavior

  • Files travel from the local computer to Google Drive.
  • New and modified files are copied into current, preserving their relative paths and file formats.
  • Before a cloud file is replaced, its previous copy is moved into a separate, uniquely named history directory.
  • Deleting a local file does not delete its existing cloud backup. The configured workflow does not automatically prune history.
  • Cloud changes are not automatically downloaded to replace local files.

Backup and recovery results must be checked against the local run reports and actual restore checks. This information page does not report the status of a particular computer or backup.

Where data goes

The backup process runs on the local computer and sends selected files directly to Google Drive over Google’s APIs. This static website does not receive files, OAuth credentials, or backup contents.

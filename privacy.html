Privacy policy

This policy describes a private backup utility operated on its operator’s own computer. It also describes this static information website. It is not an invitation for other people to connect accounts or send data.

Information accessed and its purpose

The local utility reads the files selected for backup and the file information needed to copy and verify them, including names, relative paths, sizes, modification times, and checksums. It uses Google account identity and storage quota information to verify the intended account and check available space.

Google OAuth grants the drive.file permission so the utility can create and manage its own backup files. The selected file contents and associated file information are sent to the operator’s Google Drive solely for backup, version preservation, verification, and requested recovery.

Storage and sharing

Backup files and historical copies are stored in Google Drive under the operator’s account. Local status reports and logs may contain file paths, sizes, transfer results, and error information.

OAuth tokens and the client secret are stored in restricted local credential files, separate from this website’s source. The website does not collect or store these credentials. The backup workflow does not intentionally share the backups with other accounts, sell their contents, use them for advertising, or use them to train models. The operator’s Google Drive sharing settings continue to control access to the stored files.

Google processes the data sent to Drive under its own applicable terms and privacy policy. There is no separate application server that receives the backup contents.

Retention, stopping access, and deletion

The configured backup keeps current copies and separate historical copies. Local deletion does not remove an existing cloud copy, and history is not automatically pruned.

The operator can stop the local background service and revoke the application’s permission through Google Account connections. Revocation prevents further use of that permission; it does not itself delete existing Drive backups, downloaded restores, or local logs.

To remove retained data, the operator must separately delete the appropriate current files and history from Drive, handle Drive’s Trash as desired, and remove any local restored copies or reports that should no longer be retained.

This website

These pages contain no analytics scripts, advertising, tracking pixels, application forms, or file-upload controls. They do not request OAuth tokens, account passwords, or backup data.

The website is intended for static hosting on GitHub Pages. GitHub may process ordinary request information, including visitor IP addresses, under its privacy statement. This policy does not claim that the hosting provider keeps no access logs.

Scope and changes

This application is for the operator’s private use. Any change to its permissions or data handling should be reflected here before that changed configuration is used. Questions or requests about a particular private backup should be addressed directly to its operator through the existing setup or administration channel.
